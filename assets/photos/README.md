# Photos go here 📸

Use these names (or any name — just write the same name in `js/content.js`):

- `story-1.jpg` … `story-8.jpg` → the 8 moments in "Our Story" (in order)
- `gallery-1.jpg` … `gallery-6.jpg` → "Us, In Pictures" (add more in content.js)
- `video-cover.jpg` → cover picture for the final video (optional)

Tip: phone photos are big. Under ~500 KB each makes the site load fast.
